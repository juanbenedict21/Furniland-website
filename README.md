# Furniland-website

Furniland is a web-based furniture e-commerce platform designed to provide customers with a convenient way to browse and purchase furniture products. The system includes customer and admin features for managing products, inventory, and orders.

## Project Features

- Furniture product catalog
- Shopping cart
- Customer orders
- Product and inventory management
- Admin dashboard
- Database integration
